Install Privacy Monitor

Sileo installs the native app, engine, collector, and Python dependency together. Reopen apps after installation so the engine can load. Use Choicy to exclude sensitive or unstable apps.

Public beta

For Dopamine rootless. The engine has been tested on iPhone 13 Pro Max with iOS 15.5. Native app launch and installation on a clean device are not yet verified; other devices and jailbreak types are unverified.

Recorded activity is not a verdict that an app is malicious. History stays on your device and is retained for seven days. Uninstalling preserves history.

Source, support & issues · Package checksums

Beta repository. Package indexes are currently unsigned; downloads have SHA-256 checksums. No accounts or hosted activity collection.
